文件加密（.yuexuan 容器）
作者：yuexuan

[![平台](https://img.shields.io/badge/平台-Windows-green)](#)

【这是什么】

这是一款 Windows 本地文件加密工具。
你可以把多个文件、整个文件夹拖进软件，打包成一个自定义格式的加密文件（后缀 .yuexuan）。
解密时，必须同时满足两个条件：
  1) 正确的密码
  2) 使用配套的这个软件
缺少任意一个，文件都无法打开。

设计目标是：
  · 别人拿到 .yuexuan 文件后，常见解压/加密工具无法识别，更打不开
  · 支持几十 GB 级大文件，流式处理，内存占用稳定
  · 绿色单文件，拷贝即用，不联网、不上传、无遥测


【主要功能】

1. 批量加密
   - 拖拽添加文件 / 文件夹，或用「添加文件」「添加文件夹」按钮
   - 设置密码（两次确认），可选填写「密码提示」
   - 原文件不会被修改或删除
   - 输出单个 .yuexuan 加密容器

2. 解密还原
   - 选择 .yuexuan 文件，输入密码
   - 选择输出文件夹，完整还原目录结构
   - 同名冲突可选：覆盖 / 跳过 / 自动改名（可对后续冲突全部应用）
   - 支持拖入 .yuexuan 自动进入解密模式

3. 大文件友好
   - 1 MiB 分块流式加解密（AES-256-GCM）
   - 进度条、实时速度、已用/预计剩余时间
   - 可随时取消；取消或失败会清理临时文件，不会弄坏原文件

4. 安全相关
   - 双重保护：用户密码 + 软件内置密钥因子
   - Argon2id 密钥派生（内存硬化，抗 GPU 爆破）
   - 自定义容器格式（魔数 YXENC01），非 ZIP/7z 等常见格式
   - 防篡改校验：被改动或截断会明确报错，不会解出乱码
   - 路径防护：拒绝路径穿越、junction 逃逸
   - 密码仅在内存中短暂使用，操作结束后清空输入框
   - 本机处理，不联网、无遥测、不写敏感日志

5. 界面
   - 简体中文，现代简洁浅色界面
   - 密码强度提示（含常见弱口令检测）
   - 显示/隐藏密码、快捷键（Enter 开始 / Esc 取消）
   - 加密完成后可一键打开所在文件夹


【界面角落的小字 yuexuan】

点右上角「yuexuan」可打开关于页。
这是作者标识，低调出现在界面角落。


【系统要求】

  · Windows 10 / 11（64 位）
  · 发布产物为自包含单文件 exe，无需安装 .NET


【如何使用】

  1. 双击运行 YuexuanCrypto.exe
  2. 「加密」页：拖入要保护的文件或文件夹
     · 设置并确认密码（建议 12 位以上混合字符）
     · 可选填写提示（提示可被持有本软件的人看到，不要写密码本身）
     · 选择保存位置 → 开始加密
  3. 「解密」页：选择 .yuexuan 文件
     · 输入密码，选择输出文件夹 → 开始解密

请务必牢记密码。忘记密码后，文件无法恢复。


【加密文件说明】

  · 扩展名：.yuexuan
  · 仅能用本软件 + 正确密码解密
  · 密码提示以混淆方式保存在容器中，本软件可在解密前显示
  · 旧版本格式（v1）仍可解密；新文件为 v2（Argon2id）


【从源码构建】

  依赖：
    · .NET 9 SDK
    · lib/ 目录下的 Isopoh.Cryptography.*（Argon2，已随仓库提供）

  一键构建、测试并发布：
    powershell -ExecutionPolicy Bypass -File scripts\build.ps1

  产物输出到 dist\YuexuanCrypto.exe


【项目结构】

  src/YuexuanCrypto.Core/    加密核心（格式、密钥、流式加解密）
  src/YuexuanCrypto.App/     WPF 界面
  tests/                     测试
  lib/                       Argon2 依赖
  scripts/build.ps1          构建脚本
  docs/compose/spec/         设计说明


【安全边界（请如实理解）】

  · 「必须用配套软件」指的是防止常见工具直接打开；
    若攻击者完整逆向并提取软件内置因子，仍可能自行实现解密。
  · 密码强度决定离线攻击难度，请使用强密码。
  · 密码提示对持有本软件的人可见，不要写密码本身。
